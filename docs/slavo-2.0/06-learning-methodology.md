# Learning Methodology

## Learning Cycle

**Discover → Plan → Learn → Practice → Build → Share → Review**

- **Discover:** choose a goal, current level, and reason for learning.
- **Plan:** recommend a realistic sequence with prerequisites and observable outcomes.
- **Learn:** present one focused concept with a clear example.
- **Practice:** target one skill with a specific task and success criterion.
- **Build:** apply knowledge to a tangible project or project milestone.
- **Share:** optionally publish a safe progress summary and request feedback.
- **Review:** revisit concepts through active recall and scheduled review.

## Progress Model

Track these independently:

- **Completion:** a learner finished a lesson or activity.
- **Consistency:** activity over time; useful for planning but not mastery evidence.
- **Proficiency:** demonstrated performance against explicit criteria, supported by attempts and feedback.

A lesson completion never marks a skill as mastered by itself. Feedback should point to a next improvement attempt and keep private submissions private unless explicitly shared.

## Session Shape

Target approximately 20–30 minutes, with duration configurable by the learner/path:

- 5 minutes: learn one concept.
- 10 minutes: deliberate practice.
- 10 minutes: apply the skill in a small build task.
- 5 minutes: recall and reflect.

Treat these as defaults, not a mandatory timer. A learner may shorten a session while preserving a clear objective and meaningful practice.

## Nine-Day AI From Zero Curriculum

1. What AI can and cannot do.
2. Understanding modern AI tools.
3. Writing useful prompts.
4. Context and structured instructions.
5. Research and fact-checking.
6. Building a personal AI workflow.
7. Improving through feedback.
8. Completing a mini-project.
9. Sharing results and planning next steps.

Each day should specify an objective, estimated duration, concise lesson, practical example, focused exercise, submission format, feedback criteria, reflection prompt, completion state, and optional community-sharing action. Begin with curated content and deterministic progress; add AI assistance behind a provider-independent interface only when justified.
