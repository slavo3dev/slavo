# Design System

## Direction

Classy, light editorial learning brand. Use only navy, blue, light blue, and white for interface chrome and surfaces. Keep content imagery intact where meaningful; do not introduce unrelated accent hues, gradients, or fabricated social-proof graphics.

## Tokens

- Navy: `#102A43` for primary text, navigation, and high-emphasis surfaces.
- Deep blue: `#1D4F91` for primary actions and links.
- Blue: `#3B78B8` for secondary emphasis and focus states.
- Light blue: `#EAF3FC` for quiet section backgrounds.
- Pale blue: `#F5F9FE` for subtle contrast surfaces.
- Blue border: `#D5E3F2` for dividers and outlines.
- White: `#FFFFFF` for primary page and card surfaces.

The home uses the existing Space Grotesk body face and DM Serif Display for editorial headings. Prefer compact radii, stable layouts, clear focus rings, and visible keyboard states. Respect reduced-motion preferences.

## Homepage Hierarchy

1. Shared navigation with a Learning Paths entry.
2. Hero: “Never Stop Learning.” with the secondary line “Learn something new. Practice with purpose. Build something real.”
3. Seven-stage learning system.
4. Learning-path availability grid.
5. Deliberate-practice explanation and sample session.
6. Public Porch activity and real learner progress, with privacy-safe identity.
7. Founder-led mission and final free-learning action.

Keep the hero's next-section heading visible on phone-sized first viewports. Maintain responsive order and prevent horizontal overflow. Do not rely on color alone to convey availability or status.
